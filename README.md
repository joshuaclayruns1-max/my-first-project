# 800m Tracker

A small app for 800m indoor season. It does four things:

- **Workouts:** log runs, intervals, races, and strength sessions. Shows sessions, miles, and hard days for the last 7 days.
- **Food:** log what you eat, with optional calories and protein. Shows today's totals.
- **Groceries:** a shopping list with a one-tap "runner staples" list.
- **Season plan:** a sample training week plus tips on training and eating for the 800.

Everything is saved in your browser. No account, no server.

## How to use it

Open `index.html` in a browser. Or turn on GitHub Pages:
**Settings → Pages → Source: Deploy from a branch → `main` / root → Save.**
After a minute it will be live at `https://<your-username>.github.io/my-first-project/`.
